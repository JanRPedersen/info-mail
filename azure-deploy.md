# Azure deployment notes

This project is a .NET 8 worker service and is suitable for deployment to Azure App Service or Azure Container Apps.

Recommended next steps:
1. Create a GitHub repository in your organization.
2. Push the current local repository to GitHub.
3. Create an Azure Web App or Container App for the worker service.
4. Configure the app settings for the mailbox and routing rules.
5. Connect Azure to the GitHub repository for continuous deployment.
